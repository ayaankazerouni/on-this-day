# On This Day

A map of historical events sourced from Wikipedia's On This Day feed.

To run the site locally as an [Observable Framework](https://observablehq.com/framework/) site:

Make sure you have Node installed. I'm using v22.13.1.

* Install node dependencies: `npm install`
* `npm run dev` to run the dev server at [https://localhost:3000](https://localhost:3000)
